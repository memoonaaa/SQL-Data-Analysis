# SQL-Data-Analysis

## Project Overview

This project focuses on analyzing sales data using SQL to answer business-related questions and extract meaningful insights. The analysis was performed using PostgreSQL.

## Objectives

* Analyze sales performance
* Examine order values across different coupon codes
* Compare payment methods based on order count and revenue
* Analyze product sales and quantities
* Generate business insights using SQL queries

## Tools & Technologies

* **PostgreSQL**
* **SQL**
* **VS Code**

## SQL Concepts Used

* `SELECT`
* `WHERE`
* `GROUP BY`
* `ORDER BY`
* Aggregate functions such as `COUNT()`, `SUM()`, and `AVG()`
* Data analysis using grouped queries

## Project Files

* `sales_analysis.sql` — Contains all SQL queries used for the analysis.

## Key Takeaway

This project demonstrates how SQL can be used to analyze sales data, answer business questions, and extract meaningful insights through structured queries and aggregation.
